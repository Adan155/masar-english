حزمة تحديث تصميم MASAR English Journey
======================================

المحتويات:
- styles.css: تنسيق بصري جديد بالأزرق الملكي والبنفسجي والذهبي.
- assets/masar-characters.svg: رسم متجهي لمجموعة متعلمين بالغين.
- هذا الملف: تعليمات الرفع.

تنبيه مهم:
هذه الحزمة تغيّر المظهر فقط، ولا تعدّل app.js أو الدروس أو نظام المستويات.
احتفظي بنسخة احتياطية من styles.css الحالي قبل استبداله.
رفع صورة SVG وحده لا يجعلها تظهر تلقائياً؛ يجب أن يشير عنصر صورة في index.html إلى:
assets/masar-characters.svg
لم نغيّر index.html لتقليل احتمال تعطيل الموقع.

خطوات رفع CSS من الهاتف:
1. افتحي المستودع: https://github.com/Adan155/masar-english
2. افتحي styles.css واحفظي نسخة من محتواه القديم في ملاحظة.
3. اضغطي القلم (Edit)، واستبدلي المحتوى بمحتوى styles.css في هذه الحزمة.
4. اضغطي Commit changes.
5. لرفع الرسم، افتحي مجلد assets ثم Add file > Upload files، واختاري masar-characters.svg.
6. انتظري بضع دقائق ثم افتحي الموقع وحدّثيه.

إذا لم تجدي مجلد assets أو اختلفت الواجهة عندك، توقفي وأرسلي لقطة شاشة قبل إجراء أي تغييرات إضافية.
إذا لم يعجبك التصميم، أعيدي محتوى CSS القديم من النسخة الاحتياطية.
